# ZeroHour 2026 Source Pack

This repository is a research/engineering source pack for a future Android-native Zero Hour engine project.

IMPORTANT:
- Public source repositories are kept as Git submodules pinned to exact commits.
- The user's original commercial Zero Hour game data is stored only under:
  `90_PRIVATE_NOT_FOR_GITHUB/`
- That private folder and all `.big` files are ignored by Git and must never be published.
- To restore public references after cloning this repository, use:
  `git submodule update --init --recursive`
- `ORIGINAL_GAME_DATA_SHA256.txt` contains hashes/filenames only, not copyrighted game data.
